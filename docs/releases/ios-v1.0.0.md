# SPlayer Next iOS / iPadOS 1.0.0

本仓库首个正式版，提供未签名 IPA，需要 iOS / iPadOS 16 或更高版本，自行签名后安装。

- 📱 适配 iPhone、iPad 横竖屏、安全区与前台调度窗口，宽横屏复用桌面布局。
- 🎵 网易云扫码登录、登录态保留、歌单和推荐；通过系统文件夹选择器导入本地音乐。
- 🎧 后台播放、锁屏和控制中心操作，高清封面与可选系统动态歌词。
- 💬 桌面歌词小窗支持单 / 双行、逐字歌词、音译和翻译，可调字号、颜色并实时预览。
- 🔧 修正小窗占位图标，调整唱片旋转和触摸选色。
- 🛠️ 新增“设置 → 通用 → 调试 → 日志记录”，默认关闭，开启后在系统“文件”App 的 SPlayer Next/logs 中查看。

125 项前端测试通过。未覆盖全部机型，模拟器冒烟测试暂未启用；上游桌面专属功能不代表在 iOS 可用，网易云登录仍可能受设备和网络环境影响。

原播放器来自 [SPlayer-Dev/SPlayer-Next](https://github.com/SPlayer-Dev/SPlayer-Next)，本仓库维护 iOS 适配，沿用 AGPL-3.0。
